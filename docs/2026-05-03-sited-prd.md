# SiTED 产品需求设计文档（PRD）

**项目**: SiTED - Silicon Trusted Engineering Dojo  
**版本**: 1.0  
**日期**: 2026-05-03  
**状态**: 可评审版，作为 UI/UX 设计与开发计划输入  

---

## 1. 产品概述

SiTED 是面向公司内部研发人员的 TPC 认证训练平台，帮助用户围绕编程知识、安全质量隐私、重构知识三类题库完成日常练习、错题复习、收藏沉淀和模拟考前检验。

产品主链路：

1. 用户在公司内网打开站点，系统按 IP 自动识别身份。
2. 用户按科目、语言、级别、题型、标签筛选题目。
3. 用户进入练习或背诵。
4. 系统自动沉淀练习记录、错题和收藏。
5. 用户通过模拟考试检验准备情况。
6. 题库管理员维护题目，系统管理员维护 IP 权限和基础运维配置。

产品目标：

- 降低内部研发人员练习 TPC 选择题的进入成本。
- 提供稳定、清晰、高效率的刷题与复习体验。
- 支持题库的日常维护、导入导出和基础运营统计。
- 控制首版复杂度，优先完成可用的训练闭环。

## 2. 已确认前提与产品边界

### 2.1 已确认前提

| 主题 | 结论 | 产品影响 |
|---|---|---|
| 用户身份 | 一个可访问 IP 只对应一个稳定使用者，不存在多人共享同一出口 IP | 使用 IP 作为用户身份和权限识别依据 |
| 真实 IP 获取 | 仅信任受控 Nginx 的 `X-Forwarded-For`，否则使用连接 IP | 后端需要配置可信代理，不接受任意客户端伪造头 |
| 终端范围 | 主要使用桌面 Chrome/Edge，不存在移动端使用场景 | UI 优先桌面效率，不做移动端适配 |
| 题库规模 | 预计 5 万题以内 | PostgreSQL 普通索引和简单关键字查询即可支撑 P0 |
| 图片依赖 | 少量题目需要图片，批量导入以文本题为主 | P0 支持手动上传图片；ZIP 媒体包导入导出进入 P1 |
| 模拟考次数 | 不限制次数，每次考试独立记录 | 不做报名、限次、锁题、只保留最高分等考试管理能力 |
| 多选评分 | 必须完全匹配正确选项才算正确 | 评分逻辑统一，不做部分得分 |
| 题目删除 | 题目只归档，不物理删除 | 保留历史练习记录和模拟考复盘完整性 |
| 题目版本 | 不做题目版本管理；模拟考保存试卷快照 | 普通练习查看题目当前版本，模拟考复盘查看当时快照 |
| 数据保留 | 个人训练数据长期保留，管理员可清空 | 不做自动清理策略 |
| 暗色主题 | 暗色主题为 P1 | P0 先完成 Light 主题和基础设计 token |

### 2.2 不做范围

- 不做注册、密码登录、短信、邮箱或单点登录。
- 不做复杂组织架构、团队排名、积分、徽章或证书。
- 不做多语言国际化，界面语言固定为中文。
- 不做面向公网的安全模型，部署边界限定为公司内网。
- 不做自定义角色和自定义权限组合。
- 不做全文搜索引擎、分布式文件存储、复杂缓存或消息队列。

## 3. 用户与权限

### 3.1 角色定义

| 角色 | 内部值 | 设置方式 | 能力 |
|---|---|---|---|
| 学习者 | `learner` | 默认角色 | 浏览题库、练习、背诵、错题复习、收藏、模拟考 |
| 题库管理员 | `content_admin` | 系统管理员按 IP 绑定 | 学习者能力 + 题目新增、编辑、归档、导入、导出、基础统计 |
| 系统管理员 | `system_admin` | 环境变量 `SYSTEM_ADMIN_IPS` | 题库管理员能力 + IP 角色绑定、数据清空、审计查看、配置重载 |

角色规则：

- 系统只提供固定角色，不提供自定义角色页面。
- 数据库不存储权限数组，后端根据角色枚举推导权限。
- 系统管理员只能由环境变量指定，不允许在前端移除自身系统管理员身份。

### 3.2 身份识别流程

1. 用户访问任意页面。
2. 后端从连接信息或可信代理头中解析真实 IP。
3. 后端校验 IP 是否命中 `ALLOWED_CIDR`。未命中返回 `403`。
4. 若 IP 命中 `SYSTEM_ADMIN_IPS`，身份为 `system_admin`。
5. 否则查询 `IpRoleBinding`，命中则使用绑定角色。
6. 若 IP 首次出现，创建或更新 `Visitor`，身份为 `learner`。
7. 前端启动时调用 `GET /api/me`，获得当前 IP、角色和可访问导航项。

身份设计：

- 每次 API 请求都由后端重新解析 IP 和角色。
- 前端不保存登录凭证，不实现凭证刷新链路。
- 角色变更在下一次请求生效，不需要用户登出。

## 4. 题库领域

### 4.1 科目、语言与级别

| 科目 | 内部值 | 语言 | 级别 |
|---|---|---|---|
| 编程知识 | `programming` | C、C++、Python、Java | 入门、工作、专业 |
| 安全质量隐私 | `security_privacy` | C、C++、Python、Java | 工作、专业 |
| 重构知识 | `refactoring` | 不区分语言 | 专业 |

字段定义：

| 概念 | 字段 | 说明 |
|---|---|---|
| 科目 | `subject` | `programming` / `security_privacy` / `refactoring` |
| 语言 | `language` | `c` / `cpp` / `python` / `java`，重构题为空 |
| 级别 | `level` | `entry` / `working` / `professional` |
| 题型 | `type` | `single` / `multiple` / `judgment` |
| 知识点 | `tags` | 自由标签，去重、去空格 |

合法题源组合共 21 种：

- 编程知识：4 种语言 x 3 个级别 = 12。
- 安全质量隐私：4 种语言 x 2 个级别 = 8。
- 重构知识：1 种 = 1。

后端必须在题目发布、导入和模拟考组卷时校验组合合法性。

### 4.2 题型规则

| 题型 | 内部值 | 选项数量 | 正确选项数量 | 判定 |
|---|---|---:|---:|---|
| 单选 | `single` | 2-10 | 1 | 选择完全匹配 |
| 多选 | `multiple` | 3-10 | 2-N | 选择完全匹配 |
| 判断 | `judgment` | 2 | 1 | 按单选存储，UI 展示为判断题 |

选项结构：

```json
[
  { "key": "A", "text": "选项文本", "isCorrect": false },
  { "key": "B", "text": "选项文本", "isCorrect": true }
]
```

### 4.3 内容渲染

P0 统一使用 Markdown 承载题干和解析。

| 字段 | 能力 |
|---|---|
| `stemMd` | Markdown、同源图片、fenced code |
| `explanationMd` | Markdown、同源图片、fenced code |
| `options[].text` | 纯文本 |
| `memo` | 纯文本，一句话速记 |

安全约束：

- Markdown 由服务端 sanitize 后返回。
- 图片只允许 `/uploads/...` 同源地址。
- 外链图片、`script`、`iframe`、内联事件和 `javascript:` 协议全部移除。
- 代码块通过 Markdown fenced code 渲染。

### 4.4 题目状态

| 状态 | 内部值 | 行为 |
|---|---|---|
| 草稿 | `draft` | 仅管理员可见，不进入练习和考试 |
| 已发布 | `published` | 可被学习者使用 |
| 已归档 | `archived` | 不再进入新练习和新考试，历史记录仍可查看 |

## 7. 核心业务流程

### 7.1 首次访问

1. 用户打开站点。
2. 若 IP 不在 `ALLOWED_CIDR`，显示无权限页面。
3. 若 IP 在内网范围内，后端创建或更新 `Visitor`。
4. 前端展示首页，并按角色展示可访问导航。

首页 P0 信息：

- 当前身份：IP、角色。
- 今日练习：作答数、正确率。
- 错题复习：待复习数量。
- 收藏：收藏数量。
- 模拟考：最近一次成绩和继续未完成考试入口。

### 7.2 题库浏览到练习

1. 用户在题库页选择科目、语言、级别。
2. 可选过滤题型、标签、关键字。
3. 列表展示题干摘要、题型、知识点、整体正确率。
4. 用户选择“练习”或“背诵”。
5. 系统把当前筛选条件传入对应页面。

空状态：

- 当前筛选无题：提示调整筛选或联系题库管理员。
- 题量不足以开始模拟考：提示缺少的题型和数量。

### 7.3 练习

1. 系统从筛选结果中取题，默认随机顺序。
2. 用户选择答案后提交。
3. 后端校验答案并写入 `PracticeAttempt`。
4. 若答错，写入或更新 `Mistake`。
5. 若答对且该题在未掌握错题中，`consecutiveCorrect += 1`。
6. 连续答对 3 次后标记为已掌握。
7. 前端展示结果、正确答案、解析和速记。
8. 用户进入下一题。

规则：

- 提交后不允许修改本次答案。
- 未提交离开页面不写练习记录。
- 背诵不写练习记录，也不影响错题掌握状态。

### 7.4 复习

复习页包含三个标签：

| 标签 | 内容 | 主要操作 |
|---|---|---|
| 错题 | 未掌握和已掌握题目 | 重练、标记掌握、取消掌握、移除 |
| 收藏 | 收藏题目 | 编辑备注、管理标签、取消收藏 |
| 记录 | 练习时间线 | 查看题目、重新练习 |

错题默认展示未掌握题，按最近答错时间倒序。

### 7.5 模拟考

1. 用户选择科目、语言、级别。
2. 后端检查是否已有进行中的考试。
3. 若有进行中考试，提示继续或放弃。
4. 若无进行中考试，按科目级配置组卷。
5. 题量不足时返回明确缺口。
6. 前端进入考场，展示倒计时、题目和答题卡。
7. 每次选择答案后自动保存。
8. 用户交卷或倒计时结束后，后端评分。
9. 错题批量写入 `Mistake`。
10. 前端进入复盘页。

考试规则：

- 同一用户同一时间只允许一个进行中考试。
- 倒计时以服务端 `deadlineAt` 为准。
- 关闭浏览器后再次进入可恢复。
- 超过截止时间后自动交卷，未答题计错。
- 模拟考不写 `PracticeAttempt`，只写 `ExamAttempt`。

### 7.6 题目管理

P0 使用单页表单：

- 左侧为编辑表单，分为基础信息、题干、选项、解析、发布设置。
- 右侧为实时预览，可折叠。
- 表单可保存为草稿。
- 发布前进行完整校验。

导入流程：

1. 管理员上传 JSON 文件。
2. 后端只做结构验证，不立即写入。
3. 前端展示验证报告：可导入数量、失败数量、失败原因。
4. 管理员确认后写入。
5. 任一写入失败则整批回滚。

导出流程：

- 按当前筛选条件导出 JSON。
- 导出内容不包含训练统计、创建时间、更新人等运行数据。

## 8. 模拟考配置

配置文件路径：`backend/config/exam-paper-config.yaml`。

P0 配置粒度为科目级，不按语言和级别拆分。

```yaml
defaults:
  passScorePercent: 60
  shuffleQuestions: false
  shuffleOptions: true

papers:
  programming:
    durationMinutes: 45
    sections:
      - { type: judgment, count: 8 }
      - { type: single, count: 22 }
      - { type: multiple, count: 10 }
  security_privacy:
    durationMinutes: 45
    sections:
      - { type: judgment, count: 8 }
      - { type: single, count: 22 }
      - { type: multiple, count: 10 }
  refactoring:
    durationMinutes: 60
    passScorePercent: 65
    sections:
      - { type: judgment, count: 7 }
      - { type: single, count: 25 }
      - { type: multiple, count: 18 }
```

组卷算法：

1. 根据 `subject` 读取卷面配置。
2. 根据用户选择的 `subject + language + level` 限定题源。
3. 按 section 和题型随机抽题。
4. 题量不足则返回缺口明细。
5. 生成 `ExamAttempt`，保存完整试卷快照。

试卷快照至少包含：

- 生成时的配置。
- 题目顺序。
- 每题的题干、选项、正确答案、解析、速记。
- 用户答题记录。

## 9. 数据模型（概念版）

### 9.1 Visitor

记录访问者，不承担登录账户语义。

| 字段 | 说明 |
|---|---|
| `id` | UUID |
| `ip` | 唯一 IP |
| `firstSeenAt` | 首次访问 |
| `lastSeenAt` | 最近访问 |

### 9.2 IpRoleBinding

记录非默认角色绑定。

| 字段 | 说明 |
|---|---|
| `ip` | 被绑定 IP |
| `role` | `content_admin` 或 `learner` |
| `note` | 备注 |
| `updatedByIp` | 操作人 IP |
| `updatedAt` | 更新时间 |

`system_admin` 不进入此表，只来自环境变量。

### 9.3 Question

| 字段 | 说明 |
|---|---|
| `id` | UUID |
| `sourceCode` | 可选，导入题源编号或人工编号 |
| `subject` | 科目 |
| `language` | 语言，重构题为空 |
| `level` | 级别 |
| `type` | 题型 |
| `tags` | 知识点标签 |
| `stemMd` | 题干 Markdown |
| `options` | 选项 JSON |
| `explanationMd` | 解析 Markdown |
| `memo` | 速记 |
| `status` | `draft` / `published` / `archived` |
| `totalAttempts` | 练习作答次数 |
| `correctAttempts` | 练习答对次数 |
| `createdByIp` | 创建人 IP |
| `createdAt` / `updatedAt` | 时间戳 |

### 9.4 PracticeAttempt

| 字段 | 说明 |
|---|---|
| `id` | UUID |
| `visitorId` | 访问者 |
| `questionId` | 题目 |
| `selectedKeys` | 用户选择 |
| `isCorrect` | 是否正确 |
| `durationSec` | 用时 |
| `createdAt` | 作答时间 |

### 9.5 Mistake

| 字段 | 说明 |
|---|---|
| `visitorId` | 访问者 |
| `questionId` | 题目 |
| `wrongCount` | 答错次数 |
| `consecutiveCorrect` | 连续答对次数 |
| `isMastered` | 是否已掌握 |
| `lastWrongAt` | 最近答错 |
| `masteredAt` | 掌握时间 |

唯一约束：`visitorId + questionId`。

### 9.6 Bookmark

| 字段 | 说明 |
|---|---|
| `visitorId` | 访问者 |
| `questionId` | 题目 |
| `note` | 备注 |
| `tags` | 自定义标签 |
| `createdAt` | 收藏时间 |

唯一约束：`visitorId + questionId`。

### 9.7 ExamAttempt

| 字段 | 说明 |
|---|---|
| `id` | UUID |
| `visitorId` | 访问者 |
| `subject` / `language` / `level` | 题源范围 |
| `status` | `in_progress` / `submitted` / `abandoned` |
| `paperSnapshot` | 试卷快照 |
| `answers` | 当前答案 |
| `flaggedQuestionIds` | 标记题 |
| `startedAt` | 开始时间 |
| `deadlineAt` | 截止时间 |
| `submittedAt` | 交卷时间 |
| `scorePercent` | 得分 |
| `isPassed` | 是否通过 |

### 9.8 AuditLog

## 11. UI/UX 设计输入

### 11.1 设计原则

- 这是内部学习和管理工具，不是营销网站。
- 第一屏直接进入可操作界面，不做产品介绍型首页。
- 优先服务桌面 Chrome/Edge，页面可以使用更高信息密度。
- Light 主题优先，色彩克制但状态区分清楚。
- 管理页与学习页需要有清晰视觉边界。
- 筛选、作答、复盘、导入验证等高频操作应尽量减少跳转和等待。

### 11.2 关键组件

| 组件 | 设计关注点 |
|---|---|
| 顶部导航 | 按角色展示入口，当前页面清晰 |
| 筛选条 | 科目、语言、级别联动；重构题隐藏语言 |
| 题目卡片 | 摘要、题型、标签、正确率、收藏入口 |
| 题目渲染器 | Markdown、代码块、同源图片、安全空态 |
| 答案选项 | 单选、多选、判断状态明显，提交后不可误点 |
| 练习结果 | 正误、正确答案、解析、下一题动作突出 |
| 错题列表 | 未掌握优先，掌握状态和错次清楚 |
| 考试答题卡 | 已答、未答、标记、当前题一眼可扫 |
| 题目编辑器 | 左编辑右预览，发布校验清楚 |
| 导入报告 | 成功、失败、失败原因可定位 |

### 11.3 必备状态页

- `403`：不在允许网段内。
- 空题库：提示联系题库管理员。
- 筛选无结果：提示调整筛选。
- 模拟考题量不足：列出缺少题型和数量。
- 导入验证失败：列出行号和字段错误。
- 权限不足：说明当前角色，不展示不可用操作。

## 12. 安全与运维约束

### 12.1 网络与身份

- 系统仅部署在公司内网。
- `ALLOWED_CIDR` 必填。
- 只支持 IPv4。
- 仅信任配置中的反向代理。
- 所有 API 都执行 IP 白名单校验。

### 12.2 文件上传

P0 支持手动上传图片：

- 允许类型：PNG、JPEG、WebP、GIF。
- 单文件上限：5 MB。
- 存储路径：`backend/uploads/questions/<yyyyMM>/<uuid>.<ext>`。
- 返回 URL：`/uploads/questions/<yyyyMM>/<uuid>.<ext>`。

P0 不做复杂孤儿文件回收；题目归档后图片保留。

### 12.3 数据清空

系统管理员可清空数据，范围限定为：

| 范围 | 说明 |
|---|---|
| `activity` | 练习、错题、收藏、考试记录 |
| `questions` | 题库和题库图片 |
| `all` | 题库、活动数据、角色绑定 |

清空要求：

- 请求必须包含确认短语。
- 后端写审计日志。
- `questions` 或 `all` 会删除题库图片目录。

## 13. 验收标准

### 13.1 身份与权限

- [ ] 网段外 IP 访问任意页面返回 `403`。
- [ ] 网段内 IP 首次访问自动成为学习者。
- [ ] `SYSTEM_ADMIN_IPS` 中的 IP 自动获得系统管理员权限。
- [ ] 系统管理员可以为其他 IP 分配或撤销题库管理员角色。
- [ ] 普通学习者看不到管理导航，直接访问管理接口返回 `403`。

### 13.2 题库与练习

- [ ] 21 种合法组合校验正确，非法组合无法发布题目。
- [ ] 单选、多选、判断题发布和作答规则正确。
- [ ] Markdown、代码块和同源图片可正常渲染。
- [ ] 外链图片和危险 HTML 不会被渲染。
- [ ] 练习提交后写入记录并更新题目练习统计。
- [ ] 答错题自动进入错题。
- [ ] 错题连续答对 3 次后自动标记已掌握。
- [ ] 背诵不写练习记录。

### 13.3 模拟考

- [ ] 用户可按科目、语言、级别创建模拟考。
- [ ] 题量不足时返回具体缺口。
- [ ] 进行中考试可恢复。
- [ ] 倒计时以服务端截止时间为准。
- [ ] 交卷后生成成绩和复盘。
- [ ] 模拟考错题进入错题复习。
- [ ] 模拟考不写练习记录。

### 13.4 管理与运维

- [ ] 题库管理员可新增、编辑、发布、归档题目。
- [ ] JSON 导入先验证后确认写入。
- [ ] JSON 导出不包含运行统计字段。
- [ ] 高风险操作写入审计日志。
- [ ] 数据清空必须二次确认。

## 15. 附录：JSON 导入格式（P0）

```json
{
  "version": "1.0",
  "questions": [
    {
      "sourceCode": "optional-source-id",
      "subject": "programming",
      "language": "java",
      "level": "working",
      "type": "single",
      "tags": ["集合", "线程安全"],
      "stemMd": "下面哪个集合是线程安全的？",
      "options": [
        { "key": "A", "text": "ArrayList", "isCorrect": false },
        { "key": "B", "text": "HashMap", "isCorrect": false },
        { "key": "C", "text": "ConcurrentHashMap", "isCorrect": true },
        { "key": "D", "text": "LinkedList", "isCorrect": false }
      ],
      "explanationMd": "ConcurrentHashMap 用于并发访问场景。",
      "memo": "并发集合记 Concurrent 前缀"
    }
  ]
}
```

导入校验：

- `version` 必须支持。
- `questions` 非空。
- 每题组合合法。
- 选项 key 连续且唯一。
- 正确选项数量符合题型。
- Markdown 长度、选项长度、标签数量不超过限制。
- `sourceCode` 如存在则在本次导入内不可重复。
